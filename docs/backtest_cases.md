# 方向三回测案例（资料准备，2026-09-24）

回测原则：只用事件发生**之前**已公开的公告和年报（每行财务数据带 `notice_date`），看系统能否事前把风险路径指出来；事后报道只用来确认“后来确实发生了”，不作为系统输入。

## 案例1（主案例）：安泰集团 ← 新泰钢铁 关联担保违约
- 关系：安泰集团（600408，焦化）与山西新泰钢铁同受李安民控制（兄弟公司）；新泰钢铁由李安民控制的企业100%持股。
- 担保敞口：安泰集团为新泰钢铁担保余额 2023年末 28.68亿元、2024年6月末 28.35亿元，占净资产约170%。
- 事件：2025-02-06 公告，民生银行太原分行就新泰钢铁约16.17亿元借款起诉，安泰集团承担最高4亿元保证责任；李安民所持安泰集团全部3.18亿股（31.57%）被司法冻结。
- 后续：2025-06 仍拟再为新泰钢铁担保12.16亿元；已有逾期担保4亿元，全部为新泰钢铁借款担保。
- 系统应能事前给出的路径：新泰钢铁（信用风险）→ 担保边 → 安泰集团（担保余额/净资产≈170%，承压弱）→ 控股股东股权质押（质押信号）。
- 需要的输入：2023–2024 年安泰为新泰提供担保的公告、安泰与新泰的日常关联交易公告、安泰 2023/2024 年报财务数据、李安民股份质押公告。
- 来源：[新浪财经 2025-02-07](https://finance.sina.com.cn/stock/relnews/cn/2025-02-07/doc-ineishzv9827404.shtml)、[每经网 2025-06-17](https://www.nbd.com.cn/articles/2025-06-17/3910832.html)、安泰集团临2025-022/025公告。
- 注意：安泰集团的担保开发集已用过一份公告（开发数据），回测用的是它的历史公告序列，不涉及测试成绩。

## 案例2：凌钢股份 连续亏损 → 集团兜底（同集团规则 R3 的“止损”方向）
- 2024年归母净利润 −16.78亿元（同比 −146%），2025年亏损约15.57亿元，财务费用同比翻倍。
- 2024-12 控股股东凌钢集团改由鞍钢集团控股。
- 检验点：承压评分应在 2024 年报后给出“弱”；R3 规则应体现“并入强集团后，风险沿同集团边被吸收而非外溢”。
- 来源：[新浪财经 2024年报](https://finance.sina.com.cn/stock/aiassist/yjbg/2025-03-31/doc-inerqfeh6943184.shtml)、[东方财富 2025业绩预告](https://finance.eastmoney.com/a/202601133617515386.html)、[新浪财经 实控人变更](https://finance.sina.com.cn/stock/relnews/cn/2024-12-19/doc-inczysvu0087067.shtml)。

## 案例3：方大特钢 集团内互保
- 2025-02-07 公告：方大特钢为方大炭素（600516，同受方大集团控制）提供不超过4亿元担保，方大炭素提供反担保；公司累计对外担保占净资产 45.61%，无逾期。

## 承压评分 v1 校准（2026-09-26；以下均为“校准后”，不是回测成绩）

动机：安泰回测暴露两处缺口——担保敞口未进入承压评分；单一维度极差（安泰短期偿债）被加权平均掩盖。

1. 新增“对外担保”维度：评估日有效的非子公司担保合计 / 净资产，按绝对值计分（0%→0分，≥100%→100分），权重 0.15；

2. 单一维度极差：杠杆或短期偿债维度 ≥90 分直接判弱。

v0 回测原始文件保存在 `data/archive/backtest_antai_v0/`。
