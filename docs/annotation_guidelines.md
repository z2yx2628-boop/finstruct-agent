# 标注规范（Gold Annotation Guidelines）

版本：v1（2026-09-23）。本文汇总各数据集 README 中已使用的标注口径，作为今后标注和论文附录的统一依据。
各数据集的具体争议判断仍记录在对应的 `data/gold/<数据集>/README.md` 中。

## 1. 通用原则

1. **只依据原文**：只使用公告、网页或附件原文，不使用外部知识，不推断未披露的信息。
2. **标注时不看模型预测**：标注者不得打开待测版本对该文档的预测结果。
3. **未披露填 null**：可选字段原文没有明确披露时填 `null`，列表字段填空数组。
4. **保留原始数值与单位**：金额、股数、产能不做单位换算（“10亿美元”记为 10 和“亿美元”）。
5. **日期**：统一为 `YYYY-MM-DD`；只有年月时日期字段填 `null`，原文写入对应的文字字段；“某月末”可归一为该月最后一天。
6. **公告日期**：采用公告落款日期；网页没有落款时采用页面发布日期。
7. **证据**：`evidence_text` 必须是 `source_page` 上的连续原文，不得改写、概括、跨页或拼接。网页、Word、Excel 的“页”指系统生成的文本块，证据应摘自带 `[P编号]` 或 `[R行号]` 的正文。
8. **置信度**：Gold 中统一填 1.0（表示经裁定的标签，不是模型置信度）。
9. **汇总行不是事件**：表格中的“合计”“累计”行不生成事件。

## 2. 股份质押（pledge）

1. 只记录本次业务；“累计质押情况”中的汇总行不作事件。
2. 表格每个实际业务行单独标注：新增、再次或补充质押为 `pledge`，解除为 `release`，展期或延期购回为 `extension`。
3. 股数保留公告单位（股或万股）；表头单位与正文或数量级矛盾时按正文和数量级判断，并在 README 记录。
4. 非固定日期的到期条件写入 `pledge_end_condition`。

## 3. 产能事件（capacity）

### 3.1 事件粒度
1. 每个事件表示一个独立项目或独立项目决策；同一项目的配套产能置换写入同一事件。
2. 年度固定资产投资计划、投资框架计划或其年中调整，整体只标一个 `technical_upgrade` 框架事件，不按表格行拆分，不带产能记录。
3. 同一公告独立延期、暂停或终止多个具名项目时，每个项目一个事件；表格中未延期的兄弟项目不是事件。
4. 融资、担保、借款、出资类公告中，建设项目只作背景出现时不生成事件。
5. 购买现有生产线资产、非钢铁主业项目（如数据中心）不生成产能事件。

### 3.2 事件类型
`capacity_construction` 新建；`capacity_replacement` 以产能置换为核心决策；`technical_upgrade` 技术、节能、环保、设备改造；
`commissioning` 已实际投产；`delay` 延期；`suspension` 暂停建设或暂缓实施项目；`termination` 终止或取消；
`maintenance`（V7）设施检修、停产检修或因事故、天气、限产暂时停止生产且将恢复。

### 3.3 产能记录
1. 只记录原文明确的新增或退出数值；设备规格（高炉容积、转炉吨位、生产线宽度、烧结机面积）不是产能。
2. 延期、暂停、终止项目名称或原计划中的产能是历史背景，不记录。
3. 总产能旁带“其中”的分项不重复记录；只披露建成后总规模时不改写为新增量。
4. 新建生产线的产品产量可记为产品级产能记录，即使公告称“不新增钢铁产能”，但解释时不得视为行业净新增产能。
5. **临时停产、检修或改造期间减少的产量不是产能变化**（V7）：写入 `shutdown_*` 与 `output_loss_*` 字段。

### 3.4 研究字段（V7）
1. `project_country`：境内项目填“中国”，境外项目填原文国家名；没有地点信息填 `null`，不根据公司注册地推断。
2. `decision_reasons`：只记录原文明确说明的决策原因，可多选：`trade_policy`（关税、反倾销、配额、CBAM、贸易政策）、
   `environmental_policy`、`industrial_policy`、`market_demand`、`cost_reduction`、`equipment_safety`、`financing`、
   `overseas_expansion`、`other`。“风险提示”中的可能风险不是决策原因。
3. `decision_reason_text`：摘录说明原因的一句连续原文。

### 3.5 投资与资金
1. 投资额只取项目总投资或同义表述（计划安排投资、项目核定投资额、项目概算投资、表格中的投资金额），不取注册资本、股东出资、融资额度、募集资金净额。
2. 募投项目表中“项目投资总额”记入 `investment_amount`，“拟投入募集资金”记入 `funding_source`。
3. `funding_source` 必须是资金来源（自有、自筹、募集、贷款等），单纯的金额不是资金来源。

## 4. 对外担保（guarantee）

1. 每个事件是一组“担保方→被担保方”；同一担保方为多个被担保方担保时分别标注。
2. 类型：`guarantee_provided` 已签署或已批准具体担保；`guarantee_limit` 年度额度预计或授权（按被担保方分行时逐行标注，只有总额时标一个事件且被担保方为 null）；
   `guarantee_released` 解除或到期；`guarantee_overdue` 逾期、代偿或涉诉。
3. 债权银行填入 `creditor`，不得作为被担保方。
4. 累计担保余额、对外担保余额、逾期金额只填文档级字段，不生成事件；原文明确“无逾期担保”时逾期金额填 0。
5. 被担保方注册资本、总资产、净资产、营业收入不是担保金额。
6. “主债务届满之日起三年”等期限写入 `period_text`，不推算日期。

## 5. 冻结、争议与版本

1. 测试集 Gold 必须在被测版本提交之后、首次运行之前冻结，并生成 `gold_manifest.lock`（每个文件的 SHA-256）。
2. 争议判断写入数据集 README 的“Material judgments”表，列出所选标签和可选替代标签。
3. 冻结后发现标注错误，不修改原版本，另建 `-v2` 版本并记录理由；原版本及据其生成的报告保持不变。
4. 标注者、标注日期、是否经第二人复核写入 README。

## 6. 面向论文的一致性检验（计划）

1. 每个测试集由两名标注者独立标注，按字段计算一致率，事件类型计算 Cohen's kappa。
2. 分歧逐条裁定并记录裁定理由，裁定结果作为最终 Gold。
3. 当前已冻结的 Gold 均为单人标注，引用时必须注明。
