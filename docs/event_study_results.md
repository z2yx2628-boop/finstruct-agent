2. 只看硬事件：弱组 2/49（4.1%），非弱组 3/119（2.5%）。事件少，只作描述。
3. 样本外（2019–2023 评估日）：弱组 24.2%（8/33），非弱组 9.2%（8/87），提升倍数 2.64，p = 0.0352。
