# 上下游情景路径（2026-09-27）

`src/scenario.py`，网页“上下游情景”页。**情景路径不进入正式风险路径排名，也不改变任何回测结果。**

链条：冲击 → 暴露企业 → 承压 → 钢材产品 → 下游行业 → 下游代表企业。

| 冲击 | 第一层（谁暴露） | 往下 |
| --- | --- | --- |
| 原料价格涨/跌（铁矿石、焦煤、焦炭） | 卖方：该产品占收入 ≥10% 的企业（B）；买方：公告披露的该产品关联采购（A），其余长流程钢厂只列承压最弱的 3 家（C，采购比例未披露） | 买方的主营钢材产品（B）→ 下游行业（C）→ 下游企业（B/C），标注“若成本转嫁” |
| 钢材价格涨/跌（板材、长材、特钢、钢管） | 该产品占收入 ≥10% 的生产企业（钢厂和兼营轧钢的上游企业；下游加工企业不算卖方）（B） | 下游行业（C）→ 下游企业（B/C） |
| 企业停产（可由方向一的检修/停产事件触发） | 停产企业 | 其主营钢材（B）→ 下游行业与企业；公告披露的销售对象（A，按金额取前 6） |
| 下游需求下降 | 下游行业 → 该行业使用的钢材（C） | 生产该钢材的企业（B），按承压由弱到强排序 |

证据等级：A 公告披露的交易（关联交易表中写明货物，如“关联采购：焦炭”，v1.1 起图谱保留货物名称）；
B 公司自己披露的分产品收入，或年报点名钢材为主要原材料（9 家下游代表企业中 3 家：三一重工、格力电器、中国船舶）；
C 行业常识推断，不代表企业间真实交易。排序只用于提示关注顺序（暴露 × 承压），不是风险得分。

## 企业级链条补强（2026-09-28）

新增 `data/reference/verified_product_links.csv`，仅收录能够由官方公司材料定位到双方名称和具体产品的关系，并按披露日生效：

- 铁矿石 → 宝钢股份 → 上汽集团：上交所债券募集说明书确认宝钢股份的进口铁矿石采购暴露；上汽集团官网确认双方汽车用材联合开发和应用。
- 铁矿石 → 华菱钢铁 → 三一重工：华菱钢铁2025年报确认铁矿石采购和进口依赖，并点名其超高强钢板应用于三一重工汽车起重机臂架。

两条链均为 **B级部分确认**：能够证明采购暴露、合作或产品应用，不能证明未披露的采购金额、供应份额、合同期限或实际损失。
情景图会优先显示这些企业级B级边，同时保留行业级C级路径作为补充。

## 压力暴露指数（2026-09-28）

价格冲击情景同时给出无单位的关注顺序：

`压力暴露指数 = |价格变化| × 公司披露的产品收入占比 × 财务缓冲系数 × 100`

财务缓冲系数取承压等级：弱 1.0、中 0.5、强 0.2、未评分 0.5。该指数只比较“同一情景下谁的已披露暴露更大且缓冲更弱”，
不是利润、现金流或损失预测。钢厂未披露原料采购占比时保持空值，不使用行业均值或主观假设补填。

产品层经两次预先登记的检验，方向一致但不显著（`docs/product_exposure_validation.md`、`docs/product_price_validation.md`），
因此情景页每处都注明“不预测谁会受损”。
