# 方向三：风险传导规则设计（v0，2026-09-24）

输入：`edges.csv`（边）、`signals.csv`（风险信号）、方向二承压评分快照 `data/snapshots/<日期>/fragility.csv`。
输出：风险路径，每一步给出 边的依据（公告原文/页码，或“行业近似”）+ 下一节点的承压等级与原因。

## 边的两种依据
| basis | 来源 | 报告与图上的呈现 |
| --- | --- | --- |
| `disclosed` | 公司公告（担保、关联交易），有原文与页码 | 实线，可点击查看原文 |
| `industry_approx` | 细分行业依赖表 `data/reference/industry_links.csv` | 虚线，注明“行业层面近似” |

说明：上市公司只对**关联方**披露交易对手与金额；与独立上下游企业的交易不公开（年报仅写“客户一”）。
因此跨集团的供需关系用行业节点近似，不虚构公司对公司的边。

## 四条规则
| 规则 | 触发 | 传导方向 | 例子 |
| --- | --- | --- | --- |
| R1 担保 | 被担保方出现信用事件或承压“弱” | 被担保方 → 担保方（代偿风险） | 新泰钢铁被诉 → 安泰集团承担保证责任 |
| R2 供需 | 供给中断信号（检修/停产/产能减少） | 供应方 → 采购方（断供） | 集团焦化厂停产 → 本集团钢厂 |
|  | 采购方承压“弱”或信用事件 | 采购方 → 供应方（应收款风险） | 钢厂资不抵债 → 集团内供货子公司 |
| R3 同集团 | 集团内任一成员出现高风险 | 在同一 `group_id` 内 | 强集团吸收（凌钢并入鞍钢）或集团内扩散 |
| R4 行业 | 某节点的供给中断规模足以影响行业 | 公司 → 所属行业 → 下游行业 → 该行业中承压“弱”的企业 | 大钢厂长期停产 → 钢管行业原料 → 钢管企业中最弱者 |

## 是否继续传导（每一步）
1. 查下一节点的承压等级（方向二，评估日当天的快照，防未来信息）：
   弱 → 继续传导；中 → 继续但降一级严重程度；强 → 在此停止，并记录“被吸收”。
2. 金额门槛：担保金额或交易金额占下一节点净资产/收入的比例低于阈值（v0：1%）时停止。
3. 行业近似边（R4）最多走一步，且只传给该行业中承压“弱”的企业；输出中单独标注。
4. 路径长度上限 3 步，防止无限扩散。

## 验证
- 回测案例见 `docs/backtest_cases.md`：安泰–新泰（R1）、凌钢（R3 吸收）、方大（R1+R3 对照组，应只给“关注”）。
- 阈值（1%、路径3步、等级规则）为 v0，用回测校准并记录每次改动与原因。

## v1 补充（2026-09-26）
- **集团参照等级：** 非上市集团母公司（鞍钢集团、中国宝武等，企业名称对照表中的 parent_group）没有公开财报，
  以其上市成员承压总分的净资产加权平均作为参照等级（≥60 弱，≥40 中，否则强），在路径中注明“集团参照等级”。
  这使风险可以在强集团处被吸收：2026-09-26 中国宝武参照为“强”，八一钢铁的风险在宝武处被吸收；
  鞍钢集团参照为“中”，凌钢、本钢之间的风险仍经集团传导。
- **有效期：** 只使用评估日仍有效的关系与信号，见 `docs/chain_interface.md` 第 5 节。
