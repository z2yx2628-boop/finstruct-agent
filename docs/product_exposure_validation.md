# 产品层验证：产品暴露能否解释钢企的利润分化（预先登记，2026-09-27，运行前写定）

## 要回答的问题
上下游之间没有公开的一对一交易，风险通过产品和价格传导。如果“产品暴露”是有效的传导通道，那么同一个行业冲击下，
暴露在受冲击产品上的企业应当受损更大。本检验用 2022–2023 年房地产下行（建筑用钢需求下降）作为冲击。

## 设计（写定后不改）
- **样本**：核心钢厂中，在 2022-04-30（2021 年报法定披露截止日）已能取得分品种收入的企业。
  运行前检查数据可得性：24 家可用；河钢股份（2021 年报无分品种）和重庆钢铁（各年均无分品种）排除。只看数据可得性，没有看结果。
- **暴露（冲击前，时点正确）**：`src/product_layer.exposure_as_of(code, "2022-04-30")`，即 2021 年报（细分缺失时按规则取前 3 年内最近一年）。
  长材暴露 L = 长材收入 ÷（板材 + 长材 + 特钢 + 钢管）收入；特钢暴露 S 同理。
- **结果**：毛利率变化 ΔGM = 2023 年毛利率 − 2021 年毛利率（`data/external/financials/indicators.csv`，年报数据，已经抽查 30/30 一致）。
- **统计**：Spearman 秩相关；单侧置换检验 10 000 次，随机种子 20260927。

## 成功标准
| 编号 | 假设 | 通过 | 部分通过 |
| --- | --- | --- | --- |
| H1 | 长材暴露越高，毛利率下降越多 | ρ(L, ΔGM) < 0 且单侧 p < 0.10 | ρ < 0 但 p ≥ 0.10 |
| H2 | 以长材为主（L ≥ 40%）的钢厂，ΔGM 中位数低于长材很少（L < 20%）的钢厂 | 中位数更低 | — |
| H3（对照） | 特钢不直接暴露于房地产，特钢暴露不应与更大跌幅相关 | ρ(S, ΔGM) ≥ 0 | — |

只报告、不作判定：ΔGM 取 2021→2022 和 2021→2024 的结果；每家企业的 L、S、ΔGM 明细。

## 事先说明
- 假设方向来自公开常识（2022–2023 年地产下行、建筑用钢需求下降，钢铁行业整体毛利率下滑）。
  横截面上“长材越多跌得越多”是否成立、强度多大，运行前没有计算。
- 2021 年是钢铁行业利润高点，全体企业的毛利率都可能下降；本检验只看企业之间的差异，不看整体水平。
- 成本冲击（2021 年焦炭涨价 × 焦炭外购比例）需要各钢厂的焦炭自给率，目前没有数据，不在本次检验范围内。
- 若 H1 不通过，如实记录；不调整样本、暴露定义或年份后重跑并称为验证结果。

运行：`python scripts/validate_product_exposure.py`（结果追加到本文件末尾）。

## 解读（结果出来后撰写；以下不是检验结论，只是可能的原因）
- **结论：H1、H2 未通过，H3 通过。** 2021→2023 年，长材占比高的钢厂与板材、特钢为主的钢厂，毛利率降幅基本相同
  （中位数 −6.5% 对 −6.8%）。单看产品结构，解释不了这一轮利润分化。
- 可能的原因（未检验）：
  1. 这一轮利润下滑的主因是成本端：铁矿石、焦炭价格相对钢价维持高位，所有钢厂同时受压，产品结构的差异被掩盖；
  2. 2021 年毛利率越高的企业，回落空间越大（例如方大特钢 20.0% → 6.3%），均值回归与产品结构混在一起；
  3. 只报告项中，2021→2022 年 ρ(L) = −0.273，方向与假设一致，但未作检验，也不能事后改用这个年份。
- **对项目定位的影响**：产品层可以作为“企业暴露在哪些产品上”的事实地图（B 级，公司自己披露），以及价格冲击下的情景提示；
  但**不能宣称“产品暴露能预测上下游风险传导”**，本次检验不支持这一说法。第三方向仍表述为“集团关联与担保风险网络 +
  产品暴露情景分析”。
- 按预先登记的规定，不调整样本、暴露定义或年份后重跑并称为验证结果。
