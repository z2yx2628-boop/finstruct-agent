## 盲测后的修改（2026-10-09）

盲测暴露的问题与修改：
- 投资建议和股价预测类问题（抄底、买哪只股、股价走势）没有被拒绝 → 加入明确的拒绝规则；
- 与钢铁无关的问题（“今天中午吃什么”）被“今天”误判为今日预警 → 问题必须与产业链相关，否则拒绝；
- “一首钢铁行业的诗”里的“首钢”被识别为首钢股份 → 两字简称后面紧跟“铁/材”时不算企业名；
- “会不会拖累马钢”：企业在动词之后，应为“风险来自哪里”而非“会传给谁” → 按企业与动词的先后判断方向；
- “柳钢大概排第几”未识别为承压排名 → 增加“排第/第几”，并在回答中给出该企业的名次。

修改后再用这 30 题得到的分数只能算开发集成绩；对外报告的盲测成绩是上面“仅规则，盲测”一节。修改后的准确率需要另一组新问题再测。
