# 方向二：财务承压指标（24家核心钢厂 × FY2021–2025）

数据来源：东方财富三张报表（akshare `stock_*_sheet_by_report_em`），只取年报（报告期 12-31）。
原始表可重新下载，不入库；每个文件的 SHA-256 与行数记录在 `data/external/financials/fetch_log.csv`。
输出 `data/external/financials/indicators.csv` 同时保留计算所用的原始科目（`raw_*` 列，单位：元），任何指标都可对照年报核对。

`notice_date` = 该年报的披露日。回测时只能在披露日之后使用该行（防止未来信息）。

| 指标 | 公式 | 回答的问题 |
| --- | --- | --- |
| debt_ratio 资产负债率 | 负债合计 / 资产总计 | 杠杆高不高 |
| current_ratio 流动比率 | 流动资产 / 流动负债 | 短期偿债 |
| quick_ratio 速动比率 | (流动资产 − 存货) / 流动负债 | 扣掉存货后能否偿债 |
| cash_to_short_debt 现金短债比 | 货币资金 / 短期有息负债 | 手上现金够不够还一年内到期的债 |
| short_term_debt_yi 短期有息负债 | 短期借款 + 一年内到期的非流动负债 + 应付短期债券 | 近期还款压力（亿元） |
| interest_bearing_debt_yi 有息负债 | 短期有息负债 + 长期借款 + 应付债券 | 总债务（亿元） |
| ocf_yi 经营现金流 | 经营活动现金流量净额 | 主业是否造血（亿元） |
| ocf_to_current_liab | 经营现金流 / 流动负债 | 造血能覆盖多少短期负债 |
| capex_yi 资本开支 | 购建固定资产、无形资产和其他长期资产支付的现金 | 投资扩张强度 |
| fcf_yi 自由现金流 | 经营现金流 − 资本开支 | 投资后是否还有现金 |
| gross_margin 毛利率 | (营业收入 − 营业成本) / 营业收入 | 钢价-原料价差 |
| net_margin 净利率 | 归母净利润 / 营业总收入 | |
| roe | 归母净利润 / 平均归母权益 | |
| roa | 净利润 / 平均总资产 | |
| deduct_netprofit_yi | 扣非归母净利润 | 剔除一次性收益后的真实盈利 |
| interest_coverage 利息保障倍数 | (利润总额 + 利息费用) / 利息费用 | 利润能否付息 |
| cip_to_assets | 在建工程 / 总资产 | 在建项目占用（与方向一产能事件呼应） |
| revenue_yoy | 营业总收入同比 | |
| loss_flag | 归母净利润 < 0 | |
| negative_equity | 归母权益 < 0（资不抵债），此时 ROE 置空 | |

已知口径局限（报告中需说明）：
1. “一年内到期的非流动负债”含少量租赁负债等非借款项目，短期有息负债略偏高。
2. 平均值用期初、期末两点；首年（FY2021）若缺上年数据则用期末值。
3. 担保余额 / 净资产 来自方向一担保公告，不在本表，由方向三合并。

## 如何更新（企业名单和数据都不写死）

| 需要 | 做法 |
| --- | --- |
| 新年报发布后更新数据 | `python scripts/fetch_financials.py --refresh`，再 `python scripts/build_financial_indicators.py`；年份自动延伸到最新年报，旧年份保留（带披露日，回测不受影响） |
| 临时加一家企业（如传导路径上出现的安泰集团） | `python scripts/fetch_financials.py 600408`，再生成指标表；该企业标为 `peer_group=other` |
| 分析全部42家产业链企业 | `python scripts/fetch_financials.py --all` |
| 永久加入分析范围 | 在 `data/manifests/steel_universe.csv` 加一行，并在 `data/reference/entities.csv` 加节点 |

同行排名只在 `peer_group=core`（24家核心钢厂）内做：上游焦化、下游钢管和钢厂的正常负债率不同，混在一起排名没有意义。其他企业用同一套指标，但与各自细分行业比较或只看绝对阈值。

## 实时更新与承压评分（2026-09-24）

三层数据，一条命令更新：`python scripts/update_all.py`（网页“承压评分”页也有按钮）。

| 层 | 频率 | 来源 | 指标 |
| --- | --- | --- | --- |
| 财报层 | 每季度（自动发现新财报） | 新浪财务摘要（每家1次请求）；出现新年报时自动重下东方财富三张报表 | 资产负债率、流动/速动/现金比率、经营现金流/收入、净利率、毛利率、收入增长、是否资不抵债 |
| 市场层 | 每个交易日 | 新浪日线（失败时东方财富） | 60日超额收益（减去同行中位数）、60日最大回撤、20日年化波动率 |
| 事件层 | 每天 | 方向一 `signals.csv` | 财报法定披露截止日之后的高风险信号 |

防未来信息：每个财报期只在法定截止日（一季报4-30、半年报8-31、三季报10-31、年报次年4-30）之后使用；
行情只取评估日及以前；事件只取“财报截止日 < 事件日 ≤ 评估日”。`--as-of 2025-01-31 --offline` 可还原任意历史日期的判断。

评分（`src/fragility.py`）：每个指标在24家核心钢厂内按同行分位数打 0（最强）–100（最弱）；
维度权重 杠杆0.2、短期偿债0.25、造血0.15、盈利0.2、市场0.2（缺失维度按比例重配）；
总分≥60为弱、≥40为中，否则强；红线（资不抵债、负债率≥85%）直接为弱；财报后出现高风险事件再降一档。
阈值与权重为 v0，需用回测案例校准，校准过程要记录。

每次运行生成 `data/snapshots/<日期>/`：`fragility.csv`（评分与原因）、`quarterly_metrics.csv`（输入）、`changes.md`（与上期相比的等级变化）。
定时运行：用 Windows 任务计划程序每天执行一次 `update_all.py`（数据源只能从本机访问）。

## 年报人工抽查（2026-09-26）

目的：验证 `indicators.csv` 的原始财务数据（akshare 东方财富三张报表）与年报原文一致，包括历史年度。

- 样本：6 家企业 × 5 个科目 = 30 项。宝钢股份、八一钢铁、凌钢股份、方大特钢取 2025 年报，华菱钢铁取 2024 年报，酒钢宏兴取 2023 年报（覆盖不同年度，回测会用到旧年份）。
- 科目：资产总计、负债合计、货币资金（合并资产负债表）；归属于母公司所有者的净利润（合并利润表）；经营活动产生的现金流量净额（合并现金流量表）。
- 方法：人工打开巨潮/新浪年报全文（非摘要），逐项抄录到元、到分，与系统值逐位比对。
- 结果：**30/30 完全一致（一致率 100%，精确到分）**。明细见 `data/external/financials/spot_check.csv`。
- 抽查中发现并修复的问题：原来 `indicators.csv` 的 `raw_` 字段只保留 6 位有效数字，导致与年报比对时出现舍入差；已改为保留完整精度（`scripts/build_financial_indicators.py` 的 `fmt`）。比率类指标仍保留 6 位有效数字。
- 局限：只核对了原始科目，比率由代码计算（有单元测试）；样本为 6/24 家核心钢厂，未覆盖季度数据（新浪财务摘要）。
