# 方向二：财务承压指标（24家核心钢厂 × FY2021–2025）

数据来源：东方财富三张报表（akshare `stock_*_sheet_by_report_em`），只取年报（报告期 12-31）。
原始表可重新下载，不入库；每个文件的 SHA-256 与行数记录在 `data/external/financials/fetch_log.csv`。
输出 `data/external/financials/indicators.csv` 同时保留计算所用的原始科目（`raw_*` 列，单位：元），任何指标都可对照年报核对。

`notice_date` = 该年报的披露日。回测时只能在披露日之后使用该行（防止未来信息）。

| 指标 | 公式 | 回答的问题 |
| --- | --- | --- |
| debt_ratio 资产负债率 | 负债合计 / 资产总计 | 杠杆高不高 |
| current_ratio 流动比率 | 流动资产 / 流动负债 | 短期偿债 |
| quick_ratio 速动比率 | (流动资产 − 存货) / 流动负债 | 扣掉存货后能否偿债 |
| cash_to_short_debt 现金短债比 | 货币资金 / 短期有息负债 | 手上现金够不够还一年内到期的债 |
| short_term_debt_yi 短期有息负债 | 短期借款 + 一年内到期的非流动负债 + 应付短期债券 | 近期还款压力（亿元） |
| interest_bearing_debt_yi 有息负债 | 短期有息负债 + 长期借款 + 应付债券 | 总债务（亿元） |
| ocf_yi 经营现金流 | 经营活动现金流量净额 | 主业是否造血（亿元） |
| ocf_to_current_liab | 经营现金流 / 流动负债 | 造血能覆盖多少短期负债 |
| capex_yi 资本开支 | 购建固定资产、无形资产和其他长期资产支付的现金 | 投资扩张强度 |
| fcf_yi 自由现金流 | 经营现金流 − 资本开支 | 投资后是否还有现金 |
| gross_margin 毛利率 | (营业收入 − 营业成本) / 营业收入 | 钢价-原料价差 |
| net_margin 净利率 | 归母净利润 / 营业总收入 | |
| roe | 归母净利润 / 平均归母权益 | |
| roa | 净利润 / 平均总资产 | |
| deduct_netprofit_yi | 扣非归母净利润 | 剔除一次性收益后的真实盈利 |
| interest_coverage 利息保障倍数 | (利润总额 + 利息费用) / 利息费用 | 利润能否付息 |
| cip_to_assets | 在建工程 / 总资产 | 在建项目占用（与方向一产能事件呼应） |
| revenue_yoy | 营业总收入同比 | |
| loss_flag | 归母净利润 < 0 | |
| negative_equity | 归母权益 < 0（资不抵债），此时 ROE 置空 | |

已知口径局限（报告中需说明）：
1. “一年内到期的非流动负债”含少量租赁负债等非借款项目，短期有息负债略偏高。
2. 平均值用期初、期末两点；首年（FY2021）若缺上年数据则用期末值。
3. 担保余额 / 净资产 来自方向一担保公告，不在本表，由方向三合并。
