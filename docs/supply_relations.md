# 供需关系的金额、占比与持续性（2026-09-29）

目的：让供需关系不只回答“与谁有关”，还回答“影响有多大”。所有具名交易关系汇总到一张表
`data/reference/supply_relations.csv`（`scripts/build_supply_relations.py`），网页“企业档案 → 主要客户与供应商”直接读它。

## 来源（都是 A 级：文件写明双方和数字；年报匿名行为 B 级）

| 来源 | 给出什么 | 脚本 |
| --- | --- | --- |
| 日常关联交易公告 | 关联方名称、下一年预计额度、上一年实际发生额 | 已抽取的 `edges.csv` |
| 债券募集说明书 | 集团前五名供应商、客户（金额或销量）与应收、预付、应付、合同负债余额，原表占比 | `enrich_prospectus_links.py` |
| 年报“前五名客户 / 供应商” | 前五名合计金额与占年度销售 / 采购总额比例、其中关联方部分；深交所及部分上交所公司逐行列出（多为匿名） | `download_annual_reports.py`、`extract_annual_top5.py` |

## 字段

| 字段 | 含义与规则 |
| --- | --- |
| `amount_wan` / `amount_yi` | 只放人民币金额，统一为万元和亿元（`src/amounts.py`：元、千元、万元、亿元）；外币和无法识别的单位留空，不猜 |
| `quantity` / `quantity_unit` | 销量（吨等）单独存放，`amount_type = 销量`，**永远不当作金额** |
| `amount_type` | 上年实际发生 / 预计额度（上限）/ 采购额 / 销售额 / 期末余额 / 销量 |
| `share`、`share_basis`、`share_method` | 占比及其口径。`原表披露`：文件印出的百分比；`按财报计算`：销售 ÷ 当年营业收入（有年报时用年度销售总额），采购 ÷ 年度采购总额（年报前五名金额 ÷ 其占比推出；没有年报时用营业成本近似，口径写明） |
| `years_seen`、`first_year`、`last_year`、`run_years` | 关系**实际发生**的年份数、首末年、截至最近一年的连续年数。预计额度是计划，不算；匿名的“客户一”无法跨年追踪，不算 |
| `counterparty_key` | 同一对手的简称与全称合并（例如“赤峰九联”与“赤峰九联煤化有限责任公司”） |
| `available_from` | 评估日可用的最早日期：公告日；募集说明书按余额日期；年报按法定截止日（次年 4 月 30 日） |

集中度另存 `data/reference/annual_concentration.csv`：每家企业每年的前五名客户 / 供应商合计金额与占比、关联方部分、
最大单一对象占比、由此推出的年度销售 / 采购总额，附年报页码；读不通的表（逐行合计与总额差 1% 以上）不逐行使用，标 `rows_do_not_add_up`。

## 结果（2026-09-29，24 家核心钢厂 FY2022–2025 年报 96 份）

- 前五名合计与占比：192 个“企业 × 年度 × 客户/供应商”全部读出；逐行表 16 个只列出部分对象
  （上交所年报 B 节只列前五名中的新增客户），标 `partial_table`，逐行数字照用、不据此推算最大单一占比。
- 核对：由“前五名金额 ÷ 其占比”推出的年度销售总额与新浪财务摘要的营业收入之比，中位数 1.00（102 个企业年度，范围 0.74–1.14），
  说明金额、单位和占比读取正确。
- 具名对象：核心钢厂共 138 行写明了客户或供应商名称（其余为“客户一”等匿名行），其中包括非关联的跨集团客户，
  例如本钢板材 2025 年前五名客户德邻陆港供应链服务有限公司 30.19 亿元，占年度销售总额 6.5%。
- 2025 年度中位数：前五名客户占销售 24.4%（其中关联方 11.5%），前五名供应商占采购 45.0%（其中关联方 33.8%）；
  集中度最高的是柳钢股份（客户 59.0%）和河钢股份（供应商 83.3%，其中关联方 77.9%）。
- 关系总表共 4441 行；实际发生年份 ≥ 3 年的关系 32 个。

## 局限

- 钢厂年报的前五名多为匿名，只能给出集中度，不能指认对手；具名的非关联对手主要来自集团债券募集说明书。
- 关联交易公告覆盖 2024 年以后为主，因此多数关系目前只有 1–2 个实际年份；连续年数会随年报与更早公告的补充而增加。
- 预计额度占比是“上限 ÷ 上年收入”，只说明可能的规模。
