# 事件研究：事后分析

以下检验在看到预注册结果（`docs/event_study_results.md`）**之后**设计，只作补充说明，不是预注册成绩。

## 1. 去掉 3 条控股子公司破产事件

马钢 MG-VALDUNES、中南股份子公司、山东钢铁子公司的破产程序按预注册规则计入，但比母公司自身的信用事件弱。去掉后：

- 复合 Y1：弱组 21/49（42.9%），非弱组 13/119（10.9%），提升倍数 3.92，单侧 p = 0.0000

## 2. 评分是否只是“去年亏损，今年还亏”

同一批 168 个企业×评估日上的 AUC（越接近 1 越能区分）：

| 预测变量 | AUC |
| --- | --- |
| 承压评分总分 | 0.754 |
| 评估日已公开的最近年报是否亏损（是/否） | 0.817 |
| 资产负债率 | 0.663 |
| 最近季报净利率（越低越差） | 0.903 |

**最近年报没有亏损的 133 个企业×评估日**中：弱组 5/30（16.7%），非弱组 6/103（5.8%），提升倍数 2.86，单侧 p = 0.0705。总分 AUC = 0.730。

**结论（照实）**：在以“年度大额亏损”为主的事件上，承压评分**不如**单一盈利指标——最近季报净利率的 AUC 更高，“最近年报是否亏损”也更高。这在机制上不意外：软事件就是“下一年大额亏损”，与当期净利率几乎是同一变量的延续。在最近年报没有亏损的企业中，评分仍有方向一致的区分（见上一行），但样本小、未达显著。因此对外只说“承压为弱的企业事后信用事件率明显更高（预注册通过）”，不说评分优于简单指标；评分的用处在于把杠杆、偿债、担保和市场信号放在一起给出可核对的理由，并作为传导路径的节点状态。不据此事后改权重：任何按本结果调整的评分只能称为“校准后”，且需新的样本检验。

## 3. 分年度的区分力

| 评估日 | 发生 Y1 | AUC |
| --- | --- | --- |
| 2019-04-30 | 1/24 | 0.696 |
| 2020-04-30 | 0/24 | —（无事件） |
| 2021-04-30 | 0/24 | —（无事件） |
| 2022-04-30 | 7/24 | 0.807 |
| 2023-04-30 | 8/24 | 0.680 |
| 2024-04-30 | 11/24 | 0.909 |
| 2025-04-30 | 10/24 | 0.843 |

2019–2021 年钢铁景气，窗口内几乎没有事件，这三年被判为“弱”的企业在 12 个月内都没有出事；其中安阳钢铁、八一钢铁、酒钢宏兴在 2022 年行业下行后发生了事件。结论是“承压为弱的企业在下行期更先出事”，不是“弱就一定在 12 个月内出事”。
