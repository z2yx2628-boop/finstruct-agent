## 标注口径

1. 只记录公告所述的本次业务，不把“累计质押情况”中的汇总行当作事件。
2. 表格每个实际业务行单独标注；合计行不标注。
3. 股份数量保留公告披露的原始数值和单位，不在“股”与“万股”之间换算。
4. 公告未明确披露的字段填写 `null`，不根据常识推断。
5. 日期统一写为 `YYYY-MM-DD`；非固定日期的到期条件写入 `pledge_end_condition`。
6. `source_page` 以事件主表或主要事件描述所在页为准。
7. `evidence_text` 暂采用对应来源页全文，确保可从 PDF 原文复核。完成双人复核后可进一步收缩为最短证据片段。
